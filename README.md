# Russian Railways
## Installation
1. Clone the repository:
```sh
git clone https://github.com/danielsavinoff/russian-railways-oa
```
2. Open the repository:
```sh
cd russian-railways-oa
``` 
3. Run the project locally:
```sh
npm run dev
```
4. Open it in a browser at localhost:5173.
## Key decisions
1. Project is written in Solid with the goal of maximizing performance close to pure Javascript.
2. Shadcn is used as headless component library to save the time and make it much easier to customize.
